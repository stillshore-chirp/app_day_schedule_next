# Governance Reports

UI/UX、sync、time、migration、release のレビュー報告を必要に応じてこのディレクトリへ保存します。

- filename には Issue / PR 番号と対象を含める。
- personal calendar data、account、path、raw logs を含めない。
- temporary local screenshot / trace は `docs/evidence/local/` 等の ignored path を使い、公開可能な evidence だけを commit する。
- current rule は reports ではなく `docs/ai-governance/` 本体を正本とする。
