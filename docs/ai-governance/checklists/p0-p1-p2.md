- [ ] Error loses user input or local data appears lost.
- [ ] Data loss / duplicate / silent conflict overwrite can occur.
- [ ] Naive datetime / silent DST correction / recurrence scope ambiguity remains.
- [ ] Notification can duplicate / storm without bounded policy.
- [ ] Migration / restore / import can partially apply or has no rollback.
- [ ] OAuth token / personal calendar data / secret can enter repo, DB, log, UI, artifact.
