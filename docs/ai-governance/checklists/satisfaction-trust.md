# Satisfaction and Trust Checklist

- [ ] Waiting scope is visible and existing schedules remain visible.
- [ ] Local save and Google sync are distinguished.
- [ ] Success states name what completed.
- [ ] Failure explains cause category, impact, data retention and recovery.
- [ ] Input / local work is retained where possible.
- [ ] Conflict resolution result and next sync state are clear.
- [ ] Dangerous action shows target, count, local / Google / series scope, Undo / backup.
- [ ] Notification permission and complete-exit limitation are honest.
- [ ] Sound / animation does not unexpectedly disrupt work.
- [ ] Copy does not blame the user or overstate safety.
- [ ] Routine pending state does not look catastrophic.
- [ ] Recovery and next action are available after failure.
